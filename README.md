# **hexlet-path-size** - an application for determining the size of files and directories<br>
Install:<br>
    make install<br>
Usage:<br>
    hexlet-path-size [global options]<br>
Options:<br>
    --human, -H      human-readable sizes (auto-select unit) (default: false)<br>
    --all, -a        include hidden files and directories (default: false)<br>
    --recursive, -r  recursive size of directories (default: false)<br>
    --help, -h       show help<br>
